# Python Mini Projects

A collection of five Python projects demonstrating practical skills in data cleaning, Excel automation, web scraping, email automation, exploratory data analysis, and machine learning.

## Projects

### 01. Data Cleaning with Pandas
Cleaned a customer call-list dataset by removing duplicates, standardizing values, splitting address fields, and preparing the data for use.

**Tools:** Python, Pandas, OpenPyXL

### 02. Excel Automation with Python
Automated an Excel reporting workflow by filtering and sorting records, creating a formatted report worksheet, and applying conditional formatting.

**Tools:** Python, OpenPyXL, Microsoft Excel

### 03. Web Scraping with BeautifulSoup and Requests
Extracted structured information from web pages and organized the collected data for further analysis.

**Tools:** Python, Requests, BeautifulSoup, Pandas

### 04. Automated Sales Email Report
Automated sales reporting by calculating key metrics from a CSV dataset, exporting an Excel summary, and emailing the report as an attachment.

**Tools:** Python, Pandas, OpenPyXL, SMTP

### 05. Housing EDA and Machine Learning
Explored a housing dataset through descriptive statistics and visualizations, then developed a baseline linear regression model to predict housing values.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn

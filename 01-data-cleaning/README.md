# Customer Call List Data Cleaning with Pandas

## Overview
This project demonstrates data cleaning and preprocessing using Python and Pandas on a customer call-list dataset.

## Data Cleaning Steps
- Removed duplicate records.
- Dropped an unnecessary column.
- Standardized customer names and phone numbers.
- Split address fields into separate columns.
- Normalized contact preference flags.
- Removed records that should not be contacted.
- Reset the DataFrame index.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Excel

## How to Run
1. Install the required libraries:

   `pip install pandas openpyxl`

2. Place `Customer Call List.xlsx` in the same folder as the notebook.
3. Run the notebook cells from top to bottom.

The cleaned dataset is saved as `Customer Call List Cleaned.xlsx`.

## Project Files
- `Data_Cleaning_in_Pandas.ipynb` — the data cleaning notebook.
- `Customer Call List.xlsx` — the input dataset, if safe to share publicly.
